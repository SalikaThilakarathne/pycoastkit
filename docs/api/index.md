# API reference

The reference is generated from the docstrings in the source code. Each page
documents one module. The most used functions are also available directly
from the package, for example `pck.find_storms` is `pck.storms.find_storms`.

| Module | Contents |
|---|---|
| [`pycoastkit.storms`](storms.md) | Storm detection, clusters, storm power and energy |
| [`pycoastkit.beach`](beach.md) | Profile smoothing, shoreline-relative profiles, volumes, cut and fill, slopes |
| [`pycoastkit.shoreline`](shoreline.md) | Shoreline position, foreshore slope, outlier flags |
| [`pycoastkit.sandbars`](sandbars.md) | Sandbar detection, bar state and profile type |
| [`pycoastkit.impacts`](impacts.md) | Beach change across storms |
| [`pycoastkit.recovery`](recovery.md) | Post-storm recovery |
| [`pycoastkit.vulnerability`](vulnerability.md) | Erosion classes, vulnerability and susceptibility indices, return periods |
| [`pycoastkit.waves`](waves.md) | Energy flux, surge, spectral parameters, individual waves |
| [`pycoastkit.skill`](skill.md) | Skill scores |
| [`pycoastkit.plot`](plot.md) | Figures |
| [`pycoastkit.hasaki`](hasaki.md) | Hasaki data: NOWPHAS and HORS |
